# Star Catcher: Cosmic Rush

Game HTML5 Canvas/JavaScript. Jalankan `index.html` melalui browser atau VS Code Live Server.

## Kontrol
- Panah kiri/kanan atau A/D: bergerak
- Tombol Kiri/Kanan: kontrol layar sentuh
- P: jeda / lanjut
- Enter: mulai ulang

## Daftar modifikasi
1. **Tampilan antarmuka diperbarui**: judul Cosmic Rush, panel HUD, tombol, dan latar dibuat lebih modern.
2. **Sistem combo**: setiap 4 bintang yang ditangkap berturut-turut menaikkan pengali skor hingga x5. Combo kembali nol jika terkena meteor.
3. **Bintang emas**: muncul dengan peluang 13% dari item bintang dan memberi 50 poin sebelum pengali combo.
4. **Tingkat kesulitan meningkat**: item semakin cepat dan interval kemunculan berkurang seiring waktu.
5. **Sistem jeda**: permainan dapat dijeda dan dilanjutkan dengan tombol P atau tombol Pause. Tombol akan berubah menjadi Lanjutkan saat permainan dijeda.
6. **Rekor skor**: skor tertinggi disimpan di browser menggunakan localStorage.
7. **Efek visual**: latar berbintang bergerak, efek cahaya pada pesawat dan bintang, serta visual meteor diperbarui.
8. **HUD ditambah**: menampilkan skor, nyawa, waktu, rekor, dan combo.

## Catatan
Rekor disimpan pada browser/perangkat yang sama. Menghapus data situs/browser dapat menghapus rekor.
